# 🌈 Animated Glassmorphism UI (CSS-Only)

A visually rich, animated frontend UI built using **pure HTML & CSS**.  
This project focuses on **advanced CSS animations, gradients, glassmorphism effects, and interactive UI components** without relying on JavaScript frameworks or libraries.

---

## ✨ Features

- 🎨 **Multi-layer animated gradient background**
- ❄️ **Glassmorphism container with backdrop blur**
- 🌌 **Floating SVG particle overlay**
- 🌀 **Conic gradient rotation effects**
- 🧊 **Animated feature cards with hover shine**
- 💫 **Floating icons & sparkle effects**
- 🧠 **Modal UI with smooth transitions**
- 🎭 **Responsive grid layout**
- 🚀 **Pure CSS animations (no JS required for visuals)**

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
  - Flexbox & Grid
  - Keyframe animations
  - Linear, radial & conic gradients
  - Backdrop filters
  - Pseudo-elements
  - SVG background patterns
